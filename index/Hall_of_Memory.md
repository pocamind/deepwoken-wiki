# Hall of Memory

**Content is not present in-game**  
The subject of this page is mentioned in-game, but is not tangibly implemented into the game.  
E.G. a character mentioned in a book doesn't exist as an interactible NPC.

## Description

Maintained by the [Memorial Masons](Memorial_Masons.md) the Hall of Memory is a mortuary wing within the [Citadel of Markor](The_Citadel_of_Markor.md), dedicated to the Divers who have died or retired throughout [The Divers](The_Divers.md) history. Its halls are lined with stone monoliths upon which the names of Divers are carved, with new names being added almost daily. The Hall has undergone twenty-five expansions since its construction, with another underway.[\[1\]](#cite-note-diver-1)
