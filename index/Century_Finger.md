## Description

**Century Finger** is a [Food](Food.md) item. It is exclusively purchased from [Fabantou](Fabantou.md) for 5.

It is a type of **Generic** food.

### Effect

When consumed, it replenishes 15% Stomach, but depletes -35% Water.
