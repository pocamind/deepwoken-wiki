## Description

**Pomar** is a [Food](Food.md) item.

It is a type of **Plant**, meaning it cannot be eaten with the [Carnivore](Talents.md#carnivore) Talent.

### Effect

When consumed, it replenishes 14% Stomach and 9% Water.
