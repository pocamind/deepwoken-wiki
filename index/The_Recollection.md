# The Recollection

## Description

The Recollection is a set of simulations created by the [Reclaimer of the Recollection](Reclaimer_of_the_Recollection.md) to simulate past Calamities from eyewitnesses within the [Circle of Honour](Circle_of_Honour.md). These eyewitnesses are the Ironsworn.
